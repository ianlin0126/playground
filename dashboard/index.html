Publish to GitHub Pages

Share your kid's games with family and friends from anywhere. Games will be published to a free public URL on GitHub Pages.

How to create a Personal Access Token:

  1. On GitHub, click your avatar → Settings
  2. Scroll to the bottom → Developer settings → Personal access tokens → Fine-grained tokens
  3. Click Generate new token. Give it a name (e.g. "Playground publish") and set an expiry
  4. Under Repository access, choose Only select repositories and pick your games repo
  5. Under Repository permissions, set these three to Read and write:
    • Contents — to push game files
    • Pages — to enable GitHub Pages
    • Administration — to configure the Pages source branch
  6. Click Generate token and copy it — you won't see it again
🔒 Your token is stored locally in your .env file on this machine and never sent anywhere except to GitHub. You can also update it directly in Settings →
